# 랭체인
분류: 분류:2022년 소프트웨어, 분류:CS1 - 미국 영어 인용 (en), 분류:CS1 - 영어 인용 (en), 분류:깨진 링크를 가지고 있는 문서, 분류:대형 언어 모델, 분류:소프트웨어 프레임워크, 분류:위키데이터 속성 P1273을 사용하는 문서, 분류:위키데이터 속성 P154를 사용하는 문서, 분류:위키데이터 속성 P373을 사용하는 문서, 분류:인공지능 소프트웨어, 분류:해결되지 않은 속성이 있는 문서

랭체인(LangChain)은 애플리케이션에 대형 언어 모델(LLM)의 통합을 돕는 소프트웨어 프레임워크이다. 언어 모델 통합 프레임워크로서 랭체인의 사용 사례는 문서 분석 및 자동 요약, 챗봇, 코드 분석 등 일반적인 언어 모델의 사용 사례와 크게 겹친다.


== 역사 ==
랭체인은 2022년 10월 머신러닝 스타트업 로버스트 인텔리전스(Robust Intelligence)에서 근무하던 해리슨 체이스가 오픈 소스 프로젝트로 출시했다. 2023년 4월, 랭체인은 법인을 설립했으며, 이 새로운 스타트업은 벤처 캐피털 벤치마크로부터 1,000만 달러의 시드 투자를 발표한 지 일주일 만에 벤처 기업 세쿼이아 캐피털로부터 최소 2억 달러의 가치로 2,000만 달러 이상의 자금을 조달했다.
2023년 3분기에는 작업 체인을 정의하는 선언적 방식인 랭체인 표현 언어(LCEL)가 도입되었다.
2023년 10월, 랭체인은 LCEL 코드를 상용 환경에 바로 적용 가능한 API로 호스팅하는 배포 도구인 LangServe를 출시했다.
2024년 2월, 랭체인은 LLM 애플리케이션을 위한 소스 비공개 관측 및 평가 플랫폼인 LangSmith를 출시하고, 세쿼이아 캐피털이 주도하는 2,500만 달러 규모의 시리즈 A 투자 유치를 발표했다. 2025년 5월 14일, 회사는 장시간 실행되는 상태 유지형 AI 에이전트를 배포하기 위한 관리형 인프라를 제공하는 LangGraph 플랫폼을 정식 출시했다.
2025년 4월, 랭체인은 포브스 AI 50 목록에 이름을 올렸다.


== 기능 ==
랭체인 개발자들은 챗봇, 검색증강생성, 문서 자동 요약, 및 합성 데이터 생성 등의 사용 사례에 대한 프레임워크의 적용 가능성을 강조한다. 인포월드는 랭체인을 통합된 API를 통해 대형 언어 모델과 외부 애플리케이션 간의 연결을 단순화하는 소프트웨어 개발 키트라고 설명했다. 또한 이 잡지는 PDF, 웹 페이지, CSV 파일 및 관계형 데이터베이스와 같은 소스에서 문맥을 가져오는 데 사용될 수 있으며, 개발자가 대대적인 코드 수정 없이도 기반 모델을 더 쉽게 교체할 수 있게 해준다고 기술했다.
2023년 3월 기준, 랭체인은 아마존, 구글 및 마이크로소프트 애저 클라우드 스토리지와의 통합을 포함하고 있었다. 뉴스, 영화 정보, 날씨를 위한 API 래퍼; 요약, 구문 및 의미 체킹, 셸 스크립트 실행을 위한 배시; 다수의 웹 스크래핑 하위 시스템 및 템플릿; 퓨샷 학습 프롬프트 생성 지원; 코드 내 "할 일(todo)" 작업 찾기 및 요약; 구글 드라이브 문서, 스프레드시트, 프레젠테이션의 요약, 추출 및 생성; 구글 검색 및 마이크로소프트 빙 웹 검색; 오픈AI, 앤트로픽(Anthropic), 허깅 페이스(Hugging Face) 언어 모델; 아이픽스잇 수리 가이드 및 위키 검색 및 요약; 질문 답변, 문서 결합 및 질문 생성을 위한 맵리듀스; N-그램 중복 점수 계산; PDF 파일 텍스트 추출 및 조작을 위한 PyPDF, pdfminer, fitz, pymupdf; 파이썬 및 자바스크립트 코드 생성, 분석 및 디버깅; 벡터 임베딩 저장 및 검색을 위한 Milvus 벡터 데이터베이스; 임베딩 및 데이터 객체 캐싱을 위한 Weaviate 벡터 데이터베이스; 레디스 캐시 데이터베이스 저장소; API 요청을 위한 Python RequestsWrapper 및 기타 방법; JSON 지원을 포함한 SQL 및 NoSQL 데이터베이스; 로깅 등을 위한 Streamlit; K-최근접 이웃 검색을 위한 텍스트 매핑; 시간대 변환 및 캘린더 작업; 스레드 및 비동기 하위 프로세스 실행에서의 트레이싱 및 스택 심볼 기록; 울프럼 알파 웹사이트 및 SDK 등이 포함된다. 2023년 4월 기준, 50개 이상의 문서 유형과 데이터 소스로부터 읽기가 가능하다.
